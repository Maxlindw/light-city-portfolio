# LIGHT CITY — Portfólio oficial

Portfólio público de **Light City**, uma visual novel cyberpunk brasileira original em desenvolvimento. Criador responsável pelo universo, roteiro e direção criativa.

- Idioma principal: Português (Brasil), com opção English.
- Projeto: Ren'Py, primeira temporada (adolescência).
- Situação: desenvolvimento e revisão do Episódio 3.
- Lançamento no itch.io: ainda não publicado.
- Discord oficial: ainda não disponível. Contato por mensagem privada ao criador na comunidade CTRL ALT.
- Transparência: partes dos recursos audiovisuais utilizam ferramentas de IA, com direção e curadoria humana.

## Publicação

O site usa GitHub Pages a partir de `main` / `(root)`. Após habilitar Pages, o endereço previsto é:

https://maxlindw.github.io/light-city-portfolio/

As imagens oficiais de Juh, Guh e Travessa da Barricada serão integradas na pasta `assets/` assim que forem disponibilizadas no repositório. O site possui apresentação alternativa caso esses arquivos ainda não estejam presentes.

**Não publique roteiros integrais nem materiais internos de produção neste repositório sem autorização do criador.**
